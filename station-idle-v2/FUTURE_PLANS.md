# Station Idle V2 - Future Plans & Roadmap

## Immediate Priority: Alpha 0.4 - Economy Update

### Shop System
**Goal:** Give players permanent upgrades to purchase with credits

- **Credits Currency**
  - Earned from combat victories
  - Awarded for reaching production milestones
  - Option to sell excess resources for credits
  
- **Permanent Upgrades**
  - Production Speed Boost (5%/10%/15%/25%/50%)
  - Resource Gathering Boost (10%/25%/50%/100%)
  - Power Generation Boost (25%/50%/100%)
  - Starting Resources (unlock better starting conditions)
  - Crew Efficiency (reduce consumption rates)
  - Combat Bonuses (damage, HP, shield strength)

- **Upgrade Tiers**
  - Each upgrade has 3-5 tiers
  - Costs increase exponentially
  - Visual feedback showing active upgrades

### Prestige/Reset System
**Goal:** Add replayability and long-term progression

- **Prestige Mechanics**
  - Reset all production and modules
  - Keep all shop upgrades purchased
  - Earn prestige points based on progress
  - Unlock special prestige-only upgrades
  
- **Prestige Rewards**
  - Bonus starting resources
  - Unlock new modules/recipes earlier
  - Special cosmetic options
  - Prestige currency for exclusive upgrades

- **Prestige UI**
  - Preview rewards before resetting
  - Track total prestige count
  - Show prestige-only achievements

### Achievement System
**Goal:** Give players goals and track progress

- **Production Achievements**
  - Produce X amount of each resource
  - Build all modules in a tier
  - Reach production milestones
  
- **Combat Achievements**
  - Defeat each enemy type
  - Clear all zones
  - Win without taking damage
  - Defeat X enemies total
  
- **Progression Achievements**
  - Reach certain crew counts
  - Accumulate X total resources
  - Prestige X times
  
- **Rewards**
  - Credits for each achievement
  - Unlock special modules/recipes
  - Cosmetic rewards (ship colors, UI themes)

**Estimated Completion:** 2-3 weeks

## Mid-Term Goals (Next 2-3 Months)

### Enhanced Combat
- **New Zones:** Add 2-4 more combat zones with unique themes
- **Boss Encounters:** Special high-difficulty enemies with rare rewards
- **Combat Events:** Random encounters with special modifiers
- **Fleet System:** Deploy multiple ships simultaneously
- **Equipment Crafting:** Combine materials to create custom equipment

### Research System
- **Tech Tree:** Unlock advanced technologies through research
- **Research Points:** Earned from production and combat
- **Branches:** Production, Combat, Automation, Exploration
- **Synergies:** Combine techs for bonus effects

### Station Customization
- **Visual Upgrades:** Change station appearance
- **Module Placement:** Grid-based station building
- **Efficiency Bonuses:** Adjacency bonuses for smart placement
- **Station Themes:** Unlock different visual styles

### Quality of Life
- **Batch Production:** Queue multiple recipes
- **Auto-Sell:** Automatically sell excess resources
- **Notifications:** Alert when production completes or resources are low
- **Statistics:** Detailed production/combat stats
- **Hotkeys:** Keyboard shortcuts for common actions

## Long-Term Vision (6+ Months)

### Exploration System
- **Star Map:** Navigate between different systems
- **Procedural Generation:** Discover unique systems with special resources
- **Expeditions:** Send ships on timed missions
- **Alien Encounters:** Trade, diplomacy, or combat with alien factions

### Multiplayer Features
- **Leaderboards:** Compete for highest production/combat scores
- **Trading:** Exchange resources with other players
- **Alliances:** Form groups for shared bonuses
- **PvP Combat:** Optional player vs player battles

### Advanced Automation
- **Logic Gates:** Create complex automation rules
- **Conditional Production:** Auto-start recipes based on conditions
- **Resource Routing:** Automatically distribute resources
- **AI Assistants:** Hire AI to manage subsystems

### Narrative Elements
- **Story Mode:** Guided campaign with objectives
- **Lore Discoveries:** Uncover the history of the sector
- **Character Development:** Named crew with personalities
- **Branching Choices:** Decisions that affect gameplay

### Polish & Content
- **Sound Design:** Music and sound effects
- **Animations:** Smooth transitions and visual feedback
- **Tutorial System:** Guided introduction for new players
- **More Content:** 100+ resources, 200+ recipes, 20+ zones
- **Mod Support:** Allow community-created content
