# Defender - Game Concept

## Core Concept
**Tetris meets Tower Defense** - Build permanent defensive walls using falling blocks while defending against waves of color-coded enemies.

## Gameplay Mechanics

### Block Placement System
- Tetris-style falling blocks that **don't disappear** when lines are formed
- Blocks permanently build up your defensive wall structure
- Different block types: structural blocks, turret blocks, special utility blocks
- Strategic placement determines defensive effectiveness

### Color-Based Combat System
- **Primary Colors**: Red, Blue, Yellow enemies and defenses
- **Secondary Colors**: Orange, Green, Purple (mixed from primaries)
- **Tertiary Colors**: Advanced combinations for higher-level play
- **Paint Gun Turrets**: Must match enemy color exactly to deal damage
- **Color Mixing**: Combine turret colors for versatility (Red + Blue turret = Purple shots)

### Wave Defense Structure
- **Waves**: Progressively difficult enemy formations
- **Enemy Types**: Different behaviors based on color and wave level
- **Boss Enemies**: Require multiple color hits or special combinations
- **Environmental Hazards**: Elements that can change block/enemy colors mid-game

### Roguelike Elements
- **Randomized Waves**: Different enemy patterns each playthrough
- **Block RNG**: Random block sequences keep gameplay fresh
- **Upgrade System**: Unlock new block types and turret variants
- **Meta Progression**: Permanent unlocks that affect future runs

## Technical Specifications
- **Platform**: HTML5/JavaScript for browser play
- **Art Style**: Clean, colorful pixel art emphasizing color clarity
- **Controls**: Simple mouse/keyboard for block rotation and placement
- **Session Length**: 15-30 minutes per run, high replayability

## Unique Selling Points
- **Educational Value**: Teaches color theory through gameplay
- **Strategic Depth**: Permanent building creates long-term planning
- **Accessibility**: Simple concept, complex mastery
- **Replayability**: Roguelike elements ensure fresh experiences

## Development Priority
- **Phase 1**: Core Tetris + basic color combat
- **Phase 2**: Wave system and enemy AI
- **Phase 3**: Roguelike progression and meta-systems
- **Phase 4**: Polish, balance, and advanced color mechanics
