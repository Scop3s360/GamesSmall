# Defender

**Tetris meets Tower Defense** - Build permanent defensive walls using falling blocks while defending against waves of color-coded enemies.

## Game Status
🚧 **IN DEVELOPMENT**

## Core Mechanics
- **Tetris-style block placement** that builds permanent walls
- **Color-based combat** - match turret colors to enemy colors
- **Wave defense** against increasingly difficult enemy formations
- **Roguelike progression** for high replayability

## Controls
- **WASD/Arrow Keys**: Move falling blocks
- **Q/E**: Rotate blocks left/right
- **Space**: Fast drop

## Development
- **Engine**: Godot 4.3+
- **Language**: GDScript
- **Target**: PC (Windows/Linux/Mac)
