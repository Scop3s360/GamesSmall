# Defender - Game Overview

## Title
**Defender**

## Tagline
"Build Your Wall, Paint Your Victory"

## High-Level Concept
Tetris meets Tower Defense with a color-based combat system. Place falling blocks to build permanent defensive walls, then use color-matched turrets to defend against waves of enemies. Strategic placement and color theory knowledge are key to survival.

## Target Audience
- Puzzle game enthusiasts
- Tower defense fans
- Players who enjoy strategic thinking
- Casual gamers looking for depth

## Platform
- **Primary**: Windows PC
- **Future**: Linux, Mac, HTML5 export

## Estimated Playtime
- **Single Run**: 20-45 minutes
- **Session**: 1-2 hours
- **Total Content**: 15+ hours with roguelike progression
- **Replayability**: Very High (procedural waves, random blocks)

## Core Mechanics

### Block Placement System
- Tetris-style falling blocks with rotation and movement
- Blocks remain permanently once placed (no line clearing)
- Different block types: structural, turret, utility
- Strategic placement affects defensive effectiveness

### Color Combat System
- **Primary Colors**: Red, Blue, Yellow
- **Secondary Colors**: Orange (Red+Yellow), Green (Blue+Yellow), Purple (Red+Blue)
- **Tertiary Colors**: Advanced combinations for late game
- Paint gun turrets must match enemy colors exactly
- Color mixing allows versatile turret placement

### Wave Defense
- Enemies spawn in waves with increasing difficulty
- Different enemy types with unique behaviors
- Boss enemies requiring multiple color hits
- Environmental effects that can change colors

### Roguelike Elements
- Randomized enemy waves each playthrough
- Block sequence variation
- Unlock system for new block types
- Meta-progression affecting future runs

- **Accessible**: Simple concept with complex mastery curve
